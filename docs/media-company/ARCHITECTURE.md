# Подтверждённая архитектура форка

Основа — оригинальный Agent Teams AI 2.17.10, исходный commit
`846ed19df0a2459aad59fe6ebb802a7c4b7ab972`. Electron, React, TypeScript,
существующие Kanban, команды, сотрудники, локализация и функции сохраняются.
Новые функции — расширения исходного приложения, не отдельный сервис на Python.

## Найденные точки переиспользования

- `src/features/team-runtime-recovery`: классификация отказов, recovery policy,
  порты хранилища, JSON-репозиторий, scheduler и delivery через существующие inbox.
- `src/main/services/team/AutoResumeService.ts`: возврат после сброса лимита с проверкой runId;
  это ещё не переключение между провайдерами.
- `src/features/runtime-provider-management`: штатные интерфейсы управления провайдерами.
- `src/main/services/team/runtime-control`: реестр провайдеров, события и write fence доставки.
- `src/main/services/team/provisioning`: управление запуском, остановкой и перезапуском исполнителей.
- `src/features/organizations`: организационная карта; её метаданные не запускают сотрудников.

Следующий вертикальный срез после успешной исходной сборки: одна логическая роль CEO,
упорядоченные основной/резервные исполнители, подтверждённый quota signal, checkpoint,
остановка прежнего владельца, передача управления через существующий lifecycle,
история переключения в привычном интерфейсе. Не выдавать checkpoint за продолжение вычисления.

## Изоляция запуска

Оригинал уже поддерживает переменные процесса:

- `AGENT_TEAMS_ELECTRON_USER_DATA_DIR` — отдельный Electron userData.
- `AGENT_TEAMS_ELECTRON_CLAUDE_ROOT` — отдельные команды, задачи и inbox.

Их следует направить в абсолютные пути внутри рабочей копии до любого dev-запуска.
Реальные пользовательские команды и проекты не использовать для smoke-тестов.

Новые feature slices должны следовать `docs/FEATURE_ARCHITECTURE_STANDARD.md` оригинала.
Не увеличивать существующие oversized-файлы и не добавлять facade inheritance.
