## 1. Цель
Автономная ИИ-медиакомпания: исследование рынка → ниша → сценарий → проверка фактов → видео → озвучка → монтаж → QA → согласование → публикация → аналитика → монетизация → продажи → учёт → улучшение. Владелец принимает стратегические решения, утверждает расходы, договоры, чувствительные публикации. Цели чистой прибыли (не гарантии): месяц 1 — $500, месяц 2 — $1000, месяц 3 — $2000. Первый успех: завершённый цикл, опубликованный контент, работающая аналитика, хотя бы один подтверждённый источник реального дохода. Различать потенциальный доход, начисления и полученные деньги.

## 3. Принцип
Модель — заменяемый исполнитель; сотрудник — постоянная логическая роль (идентичность, полномочия, задачи, память, история не привязаны к модели). Одна роль CEO, у неё один активный владелец управления и резервные исполнители. Не два независимых директора.

## 4. Provider Supervisor (без постоянных вызовов LLM)
Реестр провайдеров/моделей; проверка доступности; обнаружение лимитов; классификация сбоев (квота, временное ограничение, сеть, авторизация, инструмент, зависание); выбор резерва; передача задач; сохранение контекста; восстановление после перезапуска; возврат восстановившихся в пул; контроль конкуренции и дублей. Claude Code и Codex CLI через разрешённую авторизацию; OpenCode — исследовать. Состояния: AVAILABLE, BUSY, RATE_LIMITED, AUTH_REQUIRED, UNAVAILABLE, UNKNOWN (UNKNOWN ≠ доступен). Не переключаться вслепую. Сценарии: Claude исчерпан → Codex с последней безопасной контрольной точки; Codex исчерпан → Claude; оба недоступны → сохранить задания, продолжать не-LLM операции, не расходовать квоты проверками; восстановление → вернуть в пул, не прерывая активную модель. Защита: checkpoints, постоянное хранилище, lease/lock, защита от устаревшего владельца, идемпотентность, журнал, контролируемый retry. Особенно: нет повторной публикации видео, повторной отправки коммерческих сообщений, дублирования финансовых действий. Передача контекста — не «магическое продолжение», а продолжение с сохранённой точки.

## 9. Аудио
Подбор/тест голосов, естественная озвучка, произношение, музыка/эффекты, синхронизация, субтитры, права. Изучить VOICE_STRATEGY.md если есть; переиспользовать TTS. ## 10. QA
Единый конвейер: факты, визуальное соответствие, звук, субтитры, тех. качество (FFmpeg/FFprobe), лицензии, риски платформ/репутации. Мультимодальный контроль; если недоступен — фиксировать непроверенные критерии. QA может блокировать публикацию. Чувствительный контент — согласие владельца. Первые три ролика новой ниши утверждает владелец; затем директор может предложить автопубликацию; без разрешения — до пятого, потом повторный запрос. Молчание ≠ разрешение.
