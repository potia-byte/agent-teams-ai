# Решения

- 2026-10-20: самостоятельная реализация `company/` признана отклонением и остановлена
  по прямому указанию владельца. Файлы сохранены вне настоящего форка в `.abandoned-prototype`.
- 2026-10-20: настоящий upstream-форк создан в `potia-byte/agent-teams-ai`.
  Рабочая ветка предназначена для изменений внутри Electron-приложения; upstream main не менять.
- 2026-10-20: настройки прокси/TLS менять только в отдельных процессах команд.
  Не отключать проверку сертификатов; рабочий вариант — Git OpenSSL.
- 2026-10-20: полная неотфильтрованная Git-копия остаётся обязательной.
  Временный blob-filtered clone предназначен для чтения и не подменяет этот результат.
- 2026-10-20: оригинальная сборка должна пройти до реализации fallback. Зависимости,
  отсутствующие в системе, не устанавливать до ответа на уже отправленное согласование.
- 2026-10-20: авторизацию CLI не считать доказательством доступности модели или остатка квоты.
  Будущие проверки отдельно обозначают реальные CLI и имитацию отказа.
